## 📊 Project Overview

Healthcare Management Analysis is an end-to-end data analytics project designed to analyze hospital operations, patient information, appointments, doctors, billing, revenue, expenses, and patient satisfaction.

The project uses SQL Server for data storage and analysis, SSIS for ETL and data integration, Excel for data preparation, and Power BI to build an interactive healthcare management dashboard.

The dashboard provides management with a consolidated view of hospital performance, patient trends, doctor performance, financial metrics, and patient satisfaction.

## 🚀 Project Highlights
- End-to-end data analytics project
- SQL Server database implementation
- SSIS ETL pipeline
- Excel data preparation
- Power BI interactive dashboard
- Healthcare operational analysis
- Patient & doctor analytics
- Revenue and expense analysis
- Patient satisfaction analysis
- Interactive filters and navigation
- KPI-driven business reporting

## 🔍 Project Workflow
 #### Step 1 - Data Collection 
 Healthcare-related data was collected and maintained using Excel source files. 
 #### Step 2 — Data Preparation
 The source data was reviewed, cleaned and prepared for loading into the database.
 #### Step 3 — ETL Using SSIS
 SSIS was used to extract, transform and load the data into SQL Server.
 #### Step 4 — SQL Server
 SQL Server was used to store the healthcare datasets and perform data analysis using SQL queries.
 #### Step 5 — Data Modeling
 The required tables were connected and structured for analytical reporting.
 #### Step 6 — Power BI
 The SQL Server data was connected to Power BI to create the analytical model and interactive reports.
 #### Step 7 — Dashboard Development
 Interactive visuals, KPIs, filters and navigation were developed to provide a complete healthcare management solution.
